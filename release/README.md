# Coding-agent reference — local release candidate

Inspectable Python reference for durable coding-agent orchestration, conservative
dispatch accounting, native mocked function repair and versioned context recovery.
The exact candidate identity is the frozen file manifest and wheel SHA-256; version
0.1.0 is a package version, not an immutable release identity.

This unpublished candidate uses Apache-2.0 terms retained from the previous local
export, with its original contributor NOTICE. Dependency licenses remain separate;
their metadata and installed notice identities are recorded without a claim that
all redistribution obligations have been independently reviewed.

See the shipped `release/OFFLINE.md` operation guide. The authored workload oracle assets
are controller-owned offline checks. They must stay outside repair worker intake.
The tested base dependency closure excludes optional compute and production extras.

The standalone acceptance script checks installed Python, native mock transport,
an already present Docker image, exact repair/report replay, clean process restart,
context and skills checkpoint recovery, configured offline service admission and
the actual child worker's source identity, journaled container retirement, and a
disabled trusted GPU plan. The service profile serves authored scripted fixtures
on loopback with explicit authentication and a bounded persisted backlog. Explicit
one-reservation container reconciliation grants no task replay or billing authority.
No live model, GPU performance, hosted access,
public release, production readiness or human mastery is established by local checks.

The installed `agent-lab qualification-*` commands add an offline native-protocol
probe bound to one exact prepared repair. They preserve raw receipts, conservative
billing and once-only dispatch through the existing runtime. A report/handoff is
advisory evidence, with live G1/G2 explicitly pending; there is no live-enable flag.
See `release/OFFLINE.md` for the prepare/run/report/handoff order and failure rules.
