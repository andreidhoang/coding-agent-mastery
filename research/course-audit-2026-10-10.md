# Course audit: mechanisms to integrate into the existing capstone

**Decision:** the course aligns closely with our harness learning goals and supplies concrete examples for four existing gaps. Integrate compaction, skill disclosure, LSP evidence and failure-driven regressions through our current contracts. Keep our authority, effect/billing ledger, protected verification, assigned-attempt evaluation and recovery semantics. The plan needed targeted updates; no replacement architecture or second curriculum is justified.

**Evidence:** three parallel Astra source audits plus integration review, performed **2026-10-10**. Upstream [repository](https://github.com/decodingai-magazine/building-a-coding-agent-from-scratch-course) and remote main matched **4691f51e0f4977be0d3f0fc9a4667e75366f22ee**, last commit 2026-10-08. The [selected source snapshot](https://github.com/decodingai-magazine/building-a-coding-agent-from-scratch-course/blob/4691f51e0f4977be0d3f0fc9a4667e75366f22ee/README.md) preserves original bytes, license and hashes. Findings below are static source/test inspection, not newly executed failures. No course installation, course tests, paid model call, service deployment or runtime implementation was performed. Project documentation/preservation checks are recorded separately in [verification](course-audit-verification-2026-10-10.json).

**VI:** Ta học cơ chế từ source đã pin, không tin marketing hoặc coi test file là test đã chạy. Những rủi ro dưới đây là suy luận có line evidence; chưa gọi là exploit hoặc production incident đã tái hiện.

## Fit and reuse decisions

The course covers an interactive coding product: core loop, sandbox, memory/skills/LSP/compaction, bounded Explore agents, headless execution, benchmarks/regressions and trace replay/mining. Its practical CLI/editor-style workflows complement our reference's stronger emphasis on durable ownership and independent verification. Its core agent uses PydanticAI, so “from scratch” does not mean every provider/protocol layer is hand-built. Neither its breadth nor our tests establish superiority in live coding quality.

| Course contribution | Decision | Existing destination |
|---|---|---|
| Microcompaction, summary/tail splitting, full history versus active context | Adapt with artifact references, provider validation and fenced activation | H5 / M5 / `context.py`, adapters, harness, storage/recovery |
| Catalog → skill body → resources | Adapt with immutable package identity and bounded untrusted ingestion | H9 / M2/M5 / existing schemas, broker and artifacts |
| Definition/references/hover/pull diagnostics | Adapt one supervised server profile and exact-tree evidence | H6 with H2/H7/H9 / existing execution and retrieval boundaries |
| Trace mining → curated small regression → comparison | Reuse the method through existing assignments and evaluator | H8/H15 / M0/M6 / existing `evals/` and workload controls |
| In-process read-only Explore fan-out | Read as a bounded concurrency comparator | H10; retain our physical slots, global accounting and integration owner |
| Course UI, PydanticAI, Modal, Opik and Kitaru stack | Do not add as dependencies for these extensions | Existing stack already owns these responsibilities |

The canonical engineering additions are in [07](../capstone/07-reference-implementation-spec.md#course-derived-extension-contracts--proposed-2026-10-10); implementation status remains in [08](../capstone/08-implementation-coverage.md). This report owns source evidence and reasoning, not another backlog.

**VI:** Reuse ở đây chủ yếu là decomposition, thuật toán nhỏ và counterexample. Không copy runtime thứ hai rồi phải duy trì hai nơi quyết định budget, authority và completion.

## Compaction: useful transformation, insufficient recovery contract

The [microcompactor](https://github.com/decodingai-magazine/building-a-coding-agent-from-scratch-course/blob/4691f51e0f4977be0d3f0fc9a4667e75366f22ee/src/decode/context/compaction.py#L193) replaces old tool bodies in request history while the stored transcript remains available. [Tail splitting](https://github.com/decodingai-magazine/building-a-coding-agent-from-scratch-course/blob/4691f51e0f4977be0d3f0fc9a4667e75366f22ee/src/decode/context/compaction.py#L148) avoids cutting between linked tool calls/results, including inside a long tool loop. These are good small examples for deriving finite working sets from durable history.

Four details distinguish a learning mechanism from our required integration:

1. The [summary renderer](https://github.com/decodingai-magazine/building-a-coding-agent-from-scratch-course/blob/4691f51e0f4977be0d3f0fc9a4667e75366f22ee/src/decode/context/compaction.py#L235) drops tool arguments/result bodies, retaining tool names and ordinary text. The requested headings and a nonblank response cannot establish retention of a constraint or test result present only in tool output. Our projection must retain authoritative constraints and inspectable artifact references; semantic claims remain fallible.
2. [Compaction activation](https://github.com/decodingai-magazine/building-a-coding-agent-from-scratch-course/blob/4691f51e0f4977be0d3f0fc9a4667e75366f22ee/src/decode/agent/loop.py#L345) proceeds after an append error. A process can then use context its restart log cannot reconstruct. [Session-log replay](https://github.com/decodingai-magazine/building-a-coding-agent-from-scratch-course/blob/4691f51e0f4977be0d3f0fc9a4667e75366f22ee/src/decode/context/session_log.py#L108) is useful local history management, not our fenced transactional authority. Publish immutable projection bytes first, then activate with current-owner/frontier checks.
3. [Automatic triggering](https://github.com/decodingai-magazine/building-a-coding-agent-from-scratch-course/blob/4691f51e0f4977be0d3f0fc9a4667e75366f22ee/src/decode/agent/loop.py#L196) happens at would-stop, after the model/tool leg. Latest-response occupancy and the post-compaction character heuristic cannot admit every next request safely. Preserve the distinction between exact counts, estimates, stale observations and accumulated spend; inspect the complete next request before dispatch.
4. Our [current harness](../service/harness.py#L151) validates a context projection but constructs live payloads from original messages. Compaction must change the actual request-construction seam, with a digest check proving what was sent. A new helper alone would leave live requests uncompacted.

The course [survival probe](https://github.com/decodingai-magazine/building-a-coding-agent-from-scratch-course/blob/4691f51e0f4977be0d3f0fc9a4667e75366f22ee/evals/regression/cases/compaction_survival.py#L60) requests recall on seeded full history. Its [driver](https://github.com/decodingai-magazine/building-a-coding-agent-from-scratch-course/blob/4691f51e0f4977be0d3f0fc9a4667e75366f22ee/evals/harness/driver.py#L176) submits one prompt and waits for idle. Because auto-compaction follows output, a correct retained answer can predate compaction. Our test must prove activation, then ask a separate question with the original raw source messages/tool bodies absent. The fact may survive in the accepted summary or explicitly tracked retrieval; freeze which mode is tested and do not reveal the answer in the probe. This is a test-design correction, not evidence that the course cannot retain information.

**Current provider check:** Anthropic's on-demand compaction contract returns a signed block, a distinct stop reason and iteration usage. Continuation preserves that block exactly; unresolved calls and oversized compaction input are invalid. Native support is provider/model capability dependent. Our parser does not yet accept that stop reason; custom summaries do not inherit native preserved-thinking guarantees. Keep these as separate strategies with adapter and billing tests. [Official on-demand contract](https://platform.claude.com/docs/en/build-with-claude/compaction-on-demand), [thinking preservation conditions](https://platform.claude.com/docs/en/build-with-claude/compaction-thinking-blocks), checked 2026-10-10. This is current public documentation, not evidence about private Claude Code internals.

**VI:** Compaction là chọn lại evidence cho request, không xóa lịch sử hay khoản tiền chưa rõ. Giữ cặp call/result đúng cấu trúc chưa chứng minh giữ đúng nghĩa; native thinking signature còn có điều kiện riêng của provider.

## Skills: progressive context disclosure needs frozen identity

The [loader](https://github.com/decodingai-magazine/building-a-coding-agent-from-scratch-course/blob/4691f51e0f4977be0d3f0fc9a4667e75366f22ee/src/decode/skills/loader.py#L36), [catalog](https://github.com/decodingai-magazine/building-a-coding-agent-from-scratch-course/blob/4691f51e0f4977be0d3f0fc9a4667e75366f22ee/src/decode/skills/catalog.py#L26) and [payload formatter](https://github.com/decodingai-magazine/building-a-coding-agent-from-scratch-course/blob/4691f51e0f4977be0d3f0fc9a4667e75366f22ee/src/decode/skills/payload.py#L35) make metadata/body/resources easy to trace. [Name lookup](https://github.com/decodingai-magazine/building-a-coding-agent-from-scratch-course/blob/4691f51e0f4977be0d3f0fc9a4667e75366f22ee/src/decode/tools/skills.py#L28) resolves a dictionary entry rather than interpolating a model name into a path. Upstream [induced-action tests](https://github.com/decodingai-magazine/building-a-coding-agent-from-scratch-course/blob/4691f51e0f4977be0d3f0fc9a4667e75366f22ee/tests/unit/decode/tools/test_skills.py#L367) correctly separate loading instructions from authorizing the command they suggest.

Adaptation is necessary: discovery reads full files, so this is progressive disclosure to the model, not lazy filesystem parsing. Project packages silently override same-name built-ins; activation reloads discovery without binding the advertised body/resource versions. Resolving a path for provenance does not enforce containment; symlinked manifests/resources can be consumed. Recursive resource enumeration has no application budget. Safe YAML prevents object construction, not all size/alias/depth exhaustion. The seed-copy path can also dereference symlinks: [upstream workspace seeding](https://github.com/decodingai-magazine/building-a-coding-agent-from-scratch-course/blob/4691f51e0f4977be0d3f0fc9a4667e75366f22ee/src/decode/sandbox/workspace.py#L216).

Our contract freezes package provenance and bytes, limits ingestion, rejects ambiguous collisions, and routes resource/script use through existing authorization. The [Agent Skills specification](https://agentskills.io/specification) defines stricter metadata/name rules than this permissive reader; the [official integration guide](https://agentskills.io/client-implementation/adding-skills-support) supplies relevant discovery/trust guidance. Neither a package's `allowed-tools` field nor its prose can enlarge frozen task capabilities. Optional metadata support must be stated rather than claiming full conformance.

**VI:** Skill có thể giúp model biết cách làm việc mà không cấp thêm quyền. Package digest buộc catalog, body và resource vào cùng object; đổi file giữa discovery và activation phải tạo stale result, không âm thầm đổi instruction.

## LSP: semantic retrieval is a stateful process boundary

The course's [client](https://github.com/decodingai-magazine/building-a-coding-agent-from-scratch-course/blob/4691f51e0f4977be0d3f0fc9a4667e75366f22ee/src/decode/services/lsp/client.py#L36), [service](https://github.com/decodingai-magazine/building-a-coding-agent-from-scratch-course/blob/4691f51e0f4977be0d3f0fc9a4667e75366f22ee/src/decode/services/lsp/service.py#L37) and [result types](https://github.com/decodingai-magazine/building-a-coding-agent-from-scratch-course/blob/4691f51e0f4977be0d3f0fc9a4667e75366f22ee/src/decode/services/lsp/types.py#L13) illustrate stdio framing, initialization, synchronization, request IDs, lazy reuse and unavailable-versus-empty results. Definition/references/hover/pull diagnostics are directly useful for H6.

The client explicitly disallows concurrent requests, while the root-keyed global service cache has no startup/operation serialization and the tool is available to concurrent Explore children. The [out-of-order unit case](https://github.com/decodingai-magazine/building-a-coding-agent-from-scratch-course/blob/4691f51e0f4977be0d3f0fc9a4667e75366f22ee/tests/unit/decode/services/lsp/test_service.py#L186) supplies a decoy ID, not two real concurrent requests. Our initial implementation serializes requests with one reader and bounds queue/write/read/shutdown time; multiplexing is deferred.

Process policy also changes: launching a configured host command with inherited environment is not containment. One pinned server must run under our supervisor and resource/tenant boundaries. Current one-shot process execution needs a deliberate bidirectional-lifetime extension. This is a trust-boundary finding, not a claim that the inspected Python server executes malicious repository code.

Results need workspace-tree and document identity, server incarnation and encoding. The course [position conversion](https://github.com/decodingai-magazine/building-a-coding-agent-from-scratch-course/blob/4691f51e0f4977be0d3f0fc9a4667e75366f22ee/src/decode/services/lsp/client.py#L224) merely adjusts one-based coordinates; Python code points differ from UTF-16 after an emoji. Its [result URI conversion](https://github.com/decodingai-magazine/building-a-coding-agent-from-scratch-course/blob/4691f51e0f4977be0d3f0fc9a4667e75366f22ee/src/decode/services/lsp/client.py#L297) does not establish authorization for external targets. Keep exact-tree freshness, coordinate conversion and scope checks at the service seam, not only the model-facing wrapper.

Use [LSP 3.17 base protocol](https://raw.githubusercontent.com/microsoft/language-server-protocol/gh-pages/_specifications/lsp/3.17/specification.md), [encoding rules](https://raw.githubusercontent.com/microsoft/language-server-protocol/gh-pages/_specifications/lsp/3.17/types/textDocuments.md) and [pull diagnostics](https://raw.githubusercontent.com/microsoft/language-server-protocol/gh-pages/_specifications/lsp/3.17/language/pullDiagnostics.md) as the declared compatibility profile, not a claim that every server is interchangeable. The course implements pull diagnostics, not push handling. Without a prior result ID, unexpected `unchanged` is invalid; it must not become “clean.” Push support and optional diagnostic versions require later contracts.

**VI:** Một response đúng request ID vẫn có thể mô tả tree cũ. Một tool được gọi read-only vẫn có thể spawn process quyền rộng. Vì vậy cần cả protocol identity, evidence freshness và OS boundary.

## Evals: retain the method, correct the estimand and authority

The course [trial path](https://github.com/decodingai-magazine/building-a-coding-agent-from-scratch-course/blob/4691f51e0f4977be0d3f0fc9a4667e75366f22ee/evals/harness/trial.py#L162) exercises the shipped command, seeds a repository, captures artifacts and grades a fresh clone. Its task/control pattern and [failure miner](https://github.com/decodingai-magazine/building-a-coding-agent-from-scratch-course/blob/4691f51e0f4977be0d3f0fc9a4667e75366f22ee/evals/harness/mine.py#L188) support a productive loop: observe a real trajectory → preserve evidence → minimize a counterexample → add controls → compare one change. The [guessed-path regression](https://github.com/decodingai-magazine/building-a-coding-agent-from-scratch-course/blob/4691f51e0f4977be0d3f0fc9a4667e75366f22ee/evals/regression/cases/mined_guessed_file_path.py#L3) even records inefficiency within an otherwise successful task and honestly retains an unfixed status.

Our existing contracts deliberately require stronger distinctions:

| Observed course behavior | Why we adapt it |
|---|---|
| [Aggregation](https://github.com/decodingai-magazine/building-a-coding-agent-from-scratch-course/blob/4691f51e0f4977be0d3f0fc9a4667e75366f22ee/evals/harness/aggregates.py#L377) excludes infrastructure errors | Useful conditional statistic, different from our all-assigned completion. One success + one infrastructure failure gives conditional 1, assigned 1/2 |
| [Trial result](https://github.com/decodingai-magazine/building-a-coding-agent-from-scratch-course/blob/4691f51e0f4977be0d3f0fc9a4667e75366f22ee/evals/harness/trial.py#L508) can mark a correct final artifact successful after timeout/grace | Artifact correctness does not satisfy our deadline-bound fenced eligibility |
| [Verifier](https://github.com/decodingai-magazine/building-a-coding-agent-from-scratch-course/blob/4691f51e0f4977be0d3f0fc9a4667e75366f22ee/evals/harness/verifier.py#L85) overlays tests and reads a writable reward file while running candidate-dependent code on host | Clean cloning/environment scrubbing do not establish grader isolation; retain our external trusted verifier and exact-tree receipt |
| [Summary](https://github.com/decodingai-magazine/building-a-coding-agent-from-scratch-course/blob/4691f51e0f4977be0d3f0fc9a4667e75366f22ee/src/decode/runtime/summary.py#L63) excludes Explore usage; [driver](https://github.com/decodingai-magazine/building-a-coding-agent-from-scratch-course/blob/4691f51e0f4977be0d3f0fc9a4667e75366f22ee/evals/harness/driver.py#L216) summarizes outside its cap wrapper and reports retained-history usage | These surfaces cannot establish all-role cost. Optional tracing may collect more; our ledger must remain correct without it |
| [Mined path predicate](https://github.com/decodingai-magazine/building-a-coding-agent-from-scratch-course/blob/4691f51e0f4977be0d3f0fc9a4667e75366f22ee/evals/regression/cases/mined_guessed_file_path.py#L53) compares basenames; [metric](https://github.com/decodingai-magazine/building-a-coding-agent-from-scratch-course/blob/4691f51e0f4977be0d3f0fc9a4667e75366f22ee/evals/harness/metrics.py#L151) tolerates missing/malformed calls | A narrow negative predicate can pass without a successful read. Require complete evidence and separate task oracle |

Keep parent/child/retry/summary accounting even when context is pruned: 10 + 7 + 3 = 20. Never turn missing usage into free work. Miners read committed action IDs and receipts; span heuristics can confuse missing instrumentation or unresolved approvals with repeated failure. Mined cases are development regressions with lineage, not new independent benchmark samples. The existing 42 authored definitions and their controls remain one population; no held-out confirmation set exists yet. Freeze a separate eligible population before tuning or confirmation.

**Replay correction:** [ADR0019](https://github.com/decodingai-magazine/building-a-coding-agent-from-scratch-course/blob/4691f51e0f4977be0d3f0fc9a4667e75366f22ee/docs/adr/0019-kitaru-replay-runtime.md#L17) explicitly supersedes the old durable runtime with from-the-top replay and loses crash-resume/checkpoint forks. [ADR0023](https://github.com/decodingai-magazine/building-a-coding-agent-from-scratch-course/blob/4691f51e0f4977be0d3f0fc9a4667e75366f22ee/docs/adr/0023-kitaru-workers-run-locally.md#L31) makes workers local while the remote server stores results. The [current replay guide](https://github.com/decodingai-magazine/building-a-coding-agent-from-scratch-course/blob/4691f51e0f4977be0d3f0fc9a4667e75366f22ee/running_the_code/06_evals_replays.md#L168) warns about shared workspace reuse; recorded responses and real execution on cache misses answer different questions. Preserve our separate meanings of event reconstruction, trajectory counterfactual, fresh verified execution and authority-sensitive recovery. A new outcome comparison must start from a clean base.

**VI:** Evals phải nói rõ đang đo task đúng, behavior đúng, hoàn thành đúng deadline hay recovery đúng. Bốn câu hỏi không dùng chung một boolean. Replay response cũ giúp nghiên cứu trajectory, nhưng không chứng minh patch mới chạy đúng ở environment mới.

## Integration and learning outcome

Updated the existing engineering specification, coverage register, milestone mapping, H5/H6/H8/H9/H15 learning objectives, paired reading guide and context decisions. Corrected stale milestone text that still treated human learn-first evidence as a prerequisite for the authorized reference build. Human predictions/teach-backs remain unassessed.

Engineering order: regression/evidence controls → deterministic accepted context projections → accounted semantic compaction; immutable skills can proceed after shared identity contracts agree; LSP follows its supervised process boundary. The main research result remains fixed-envelope 1/2/4 scaling and one fixed-N allocation comparison. These extensions become individual ablations only when their question warrants measurement. No automatic four-feature bundle or duplicate pilot.

Independent Astra integration review found two design ambiguities and they were corrected: compactor dispatch/receipt events must be allowed to advance the event frontier without invalidating their own projection, while unrelated source progress still invalidates it; retention probes must remove original source messages, not forbid the retained fact in the summary. The revised contract adds a successful-accounted-activation control and freezes summary-only versus retrieval-assisted probe semantics. A final evaluation/curriculum review also clarified that held-out confirmation is still to be frozen, exact-candidate verification is distinct from acceptance/review, and absence of a wrong read is not a task-success oracle. This is AI design review, not executed implementation or independent human reproduction.

**Ready:** the next bounded course-derived implementation slice is specified. This extension order does not displace required delivery in the separate [hackathon profile](../hackathon/README.md). **Still unimplemented/unmeasured:** these four extensions, automatic active-attempt recovery, replanning/general live coordination, broader production lifecycle, live quality/scaling and operated SLOs. October 9 test results remain dated evidence; current source also contains later Nebius support with its [separate verification](hackathon-2026-10-10/verification.json), which this documentation audit did not rerun. Concurrent provider/document changes were preserved and are distinguished in this audit's preservation record. No hiring or frontier-scale capability is inferred.

**VI:** Plan đã đủ cụ thể để bắt đầu slice tiếp theo, không có nghĩa service đã production-ready. Việc học của Huy vẫn đi từ H0, rồi trace các cơ chế mới đúng module khi đến lượt; AI build không tự điền mastery.
