# Nebius first-slice implementation evidence

2026-10-10. AI-authored implementation and deterministic mock evidence; independent review is pending. This does not establish human mastery, authenticated model availability, live token-cap enforcement, NVIDIA-model coding capability, or production readiness.

Implemented in `service/providers.py`, `service/protocol.py`, `service/context.py`, `service/harness.py`, with distinguishing tests in `tests/test_nebius_provider.py`. The adapter requires an explicit model, defaults to disabled network, and allows only `https://api.tokenfactory.nebius.com/v1/` in this slice. Regional endpoints are intentionally absent. The owned HTTP transport has zero retries, and redirects are explicitly disabled even on an injected redirect-enabled mock client. Injected clients are trusted dependencies and must themselves use a no-retry transport.

Native Chat Completions requests use function tools, `n=1`, `stream=false`, `tool_choice=auto` and bounded `max_tokens`. Exact assistant messages, including opaque reasoning and future provider fields, continue unchanged; linked native tool messages follow in call order. Immutable request artifacts bind provider, protocol, endpoint and payload to the durable dispatch digest. Restored evidence rejects adapter identity drift. Native linkage rejects orphan, missing, reordered and duplicate tool results or call IDs before further HTTP or tools.

The harness persists complete bounded response bytes before strict UTF-8/JSON decoding or usage parsing. Valid usage settles before model identity, finish state or tool semantics are accepted. Missing/malformed usage keeps the retained raw receipt and conservative liability; timeout or response overflow remains Unknown with no invented complete receipt. Duplicate dispatches consume saved bytes and cannot repeat requests or edits. Existing Anthropic and scripted semantics remain exercised by regressions.

Billing example: prompt 100, cached 30, completion 20 with reasoning 12 maps to input 70, cache-read 30 and output 20. Reasoning contributes no additional charge. At synthetic rates 10000/1000/20000 micro-USD per million input/cache/output tokens, one integer ceiling yields 2 micro-USD. These synthetic rates are fixture evidence only. Live output enforcement, input-bound evidence, cache rates and model aliases require separate authoritative preflight before paid execution.

Measured check: `.venv/bin/python -m pytest -q tests/test_nebius_provider.py tests/test_live_harness.py tests/test_protocol.py tests/test_engine.py` — **82 passed in 3.88 seconds**. `.venv/bin/ruff check service/providers.py service/harness.py service/context.py service/protocol.py tests/test_nebius_provider.py` — **all checks passed**. Coverage includes native read→guarded edit→finish, exact reasoning continuation/checkpoint, replay without HTTP/edit repetition, usage settlement for rejected semantics and model mismatch, retained liability for malformed counters/JSON, token-bound revocation, timeout, disabled/unapproved configuration, endpoint/redirect rejection and context/request/response byte limits. No live HTTP, credential loading, paid calls or deployments occurred.

**VI:** Kết quả đo là protocol và accounting trên HTTP mock, không phải model thật đã sửa repository chưa thấy. Raw body chứng minh response nhận được; usage hợp lệ chứng minh charge; tool proposal hợp lệ mới được đưa qua broker. Ba lớp evidence đó vẫn tách biệt khi response bị `length`, sai model hoặc thiếu usage. Mastery H0 của Huy không được suy ra từ test AI chạy.

## Independent review repair, 2026-10-10

Astra identified nullable fields in the official Nebius OpenAPI schema. The initial 82-test record above remains the initial result; this section records the subsequent repair. `tool_calls:null` now produces an empty validated proposal without changing the raw assistant field. A `stop` response may finish with null tools; `finish_reason:tool_calls` still requires real validated calls. Null/missing usage-detail objects, cached/reasoning subsets and other optional detail counters are treated as absent breakdown evidence. Non-null counters must still be bounded nonnegative integers; cached/reasoning subsets may not exceed their aggregate counts, and total consistency remains enforced.

The conservative missing-cache policy is explicit: a null/missing cached breakdown receives zero inferred discount, so all aggregate prompt tokens are billed at the approved input rate. Unknown cache premiums are not inferred. Reasoning null provides no subset evidence and does not add output charge. Exact raw nullable fields survive saved evidence, native continuation and replay.

Post-repair measured check: the same focused suite now reports **97 passed in 4.07 seconds** (66 Nebius cases and 31 existing regressions); Ruff on the same source/test paths reports **all checks passed**. Fifteen additional schema regressions distinguish nullable acceptance from malformed non-null counters and reject a null-tool `tool_calls` finish after settling valid usage. A synthetic rate of 100000 micro-USD per million input tokens distinguishes charging all prompt 100 with no known cache discount (11 micro-USD including completion 20) from cached 30 (8 micro-USD), rather than hiding the policy behind equal rounded bills. No live provider calls occurred.

**VI:** `null` là field hợp lệ nhưng chưa có breakdown, khác với counter âm hoặc lớn hơn tổng. Repair cho phép protocol hợp lệ tiếp tục mà không đổi bytes evidence; accounting vẫn tính prompt chưa rõ cache theo input rate đã duyệt. Test chọn rate fixture làm hai khoản charge khác nhau để thật sự phân biệt có/không discount sau rounding.

Astra's follow-up identified the prerequisite for that missing-cache policy: input billing covers every unknown cached allocation only when the approved cache-read rate is no greater than the input rate. The first Nebius slice now **rejects `cache_read_per_million > input_per_million` before any dispatch or HTTP request**. This gate applies only to Nebius; a distinguishing test also exercises an Anthropic envelope with a cache premium and confirms its existing behavior remains supported. Unknown cache premiums are rejected rather than silently undercharged. Final post-review focused check: **98 passed in 4.13 seconds** (67 Nebius cases plus 31 existing regressions); Ruff passed. The earlier 82/97 records above remain dated intermediate evidence.

**VI:** Giả sử input rate thấp hơn cache rate thì “tính mọi prompt theo input” có thể undercharge dù reservation ban đầu lớn. Gate mới loại envelope đó trước dispatch cho Nebius, nên cách xử lý cached breakdown `null` thật sự giữ được accounting bảo thủ trong phạm vi đã hỗ trợ.
