# Study workspace

Learning here follows [D046](../context/decision-log.md#d046-production-backward-learning-replaces-mastery-gates): start from a real artifact, trace it down until you can predict and change it, and ship something useful. Each trace gets one dated note here and one row in the [trace log](../docs/05-mastery-tracker.md). The [H0–H15 modules](../docs/02-mastery-learning-plan.md) are a concept reference that traces draw on, not a schedule.

**VI:** Mỗi trace bắt đầu từ một thứ đang chạy thật và dừng khi em tự đoán và tự sửa được. Cần khái niệm nào thì tra khái niệm đó trong H0–H15, không học theo thứ tự.

- `packets/`: concept explanations with tiny examples and inspected code. They are reference material; open one when a trace reaches its concept.
- `sessions/`: trace notes, named `YYYY-MM-DD-trace-topic.md`, plus Huy's own prediction files. Older notes keep their original names.
- `templates/session-note.md`: the trace note template.

**Now:** the first trace starts from the G1 live call. Before that call, the S0 [prediction file](sessions/2026-10-14-H0-live-G1-prediction.md) stays as a pre-registration that Huy writes alone. It is experiment design, not a test, and Huy can drop it by saying so. The [H0 reference runtime](packets/H0-reference-runtime.md) and the [original small lab](packets/H0-system-boundaries.md) remain available as background. Defect experiments stay inside disposable copies.

Only Huy writes Huy's fields. AI help is labeled in the note.
