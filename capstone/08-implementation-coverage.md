## Remaining source work

**NVIDIA:** NV-S0 is delivered; the new authored trusted-probe preparation covers only part of NV-S1's measurement mechanics. The full generated-CUDA build/loading boundary, device fencing/health/retirement and production GPU isolation remain unimplemented and hardware-unqualified. NV-S2 agent optimization, NV-S3 profiler intervention and NV-S4 reviewed-data use remain later dependent slices. Reuse existing skills/evidence components; no second runtime or benchmark population is added.

**Course-derived:** failure-to-regression, deterministic offloading and immutable skills capture→broker→disclosure→typed recovery are delivered under their frozen bounded contracts. Semantic/native compaction, supervised LSP, broader failure mining and fresh candidate/outcome trials remain unimplemented. No live skill-usefulness or context-quality gain has been measured.

These are real implementation gaps relative to the broader production/curriculum target; deployment access alone does not complete them.

1. **Automatic recovery supervisor:** reconcile unknown external effects/billing and observed environment retirement, replace active attempts with current authority, and resume supported checkpoints across interrupted processes. The new local Docker journal supplies explicit bounded physical cleanup; automatic remote-effect/billing reconciliation, replacement and resume still require additional coordination.
2. **Graph revision and general live coordination:** frozen DAGs cannot be replanned in place; descendant invalidation and new-generation execution are absent. The legacy fixture coordinator uses known fixture edits; the October10 supported function-repair coordinator uses native tool proposals without importing reference edits. Build arbitrary-authorized-repository/dependency-aware planner/worker integration before claiming a general live coding service. Live NVIDIA capability and account conformance remain unmeasured.
3. **Context lifecycle and repository discovery:** automatic protocol-preserving rollover/semantic compaction, richer symbol/AST retrieval and full MCP/skill extension lifecycle are absent. Semantic summaries are lossy and must not be described as lossless memory. The opt-in context path can offload eligible old tool bodies and retrieve them through the accepted allowlist; irreducible oversized requests still fail closed. Legacy and Anthropic paths retain full history. Local bounded search and freshness checks are implemented; the remaining extension contracts are proposed behavior.
4. **Production service lifecycle:** fair queued admission, richer burst/fairness policy, durable retention/GC, identity/secret rotation, general active-run/rolling schema upgrades, configured live-service bootstrap and fully integrated telemetry/release automation. A bounded offline schema-1→2 migration now exists; it does not supply those rolling/compatibility operations. Integration currently uses head comparison and current store incarnation, without a separate leased integrator epoch. Final eligibility stores database decision time, without a separate persisted commit-confirmation timestamp. Full infrastructure cost accounting is absent. The offline fixture service now provides configured bootstrap and persisted backlog caps; it does not complete the whole operating platform.
5. **Deeper GPU/training extensions when selected:** full model layer/sampling path, serving-engine integration and real batching/KV residency, selected kernel/warp profiling, gradient/optimizer/distributed training loops. Current math, simulators and CUDA benchmark preparation are inspectable starting points.

**VI:** Khi học hoặc refactor, chọn một gap và giữ invariant/test cũ. Ví dụ muốn tự động recovery thì phải chứng minh duplicate dispatch không chạy lại effect chưa rõ; không thể chỉ thêm retry vào loop rồi gọi là durable.
