# Study handoff template

Copy into a session note or use to refresh `context/current-state.md`. Keep it concise; use links instead of duplicating source documents.

```text
Date / author:
Objective / current trace / capstone mapping:
Mode: study / experiment / implementation / review
What Huy traced or wrote (link, or none yet):
Established facts and their scope:
Sources / code / artifacts inspected:
Predictions and their authors:
Open question or awaited response:
Unresolved assumptions / effects / liabilities:
Files changed and why:
Next step and prerequisites:
Engineering gate status (G1–G5) and evidence needed:
```

**VI:** Nếu Huy chưa viết gì, ghi “none yet”. Handoff cần đủ để agent mới không tự tạo evidence hoặc lặp lại một experiment chỉ vì nó quên kết quả cũ.
